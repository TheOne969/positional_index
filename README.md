# Information Retrieval: Positional Index Hindi

A low-latency, memory-efficient **Positional Inverted Index** built in Python from Hindi Wikipedia articles. The system supports **Exact Phrase Search** and  **Proximity Search** (finding terms within a specified distance).  
  
Dataset: [Hindi Wikipedia XML Dump](hiwiki-latest-pages-articles.xml.bz2) ::
Official Wikimedia dump containing all encyclopedic Hindi Wikipedia articles written in the Devanagari script.

[Github Link](https://github.com/TheOne969/positional_index)

---

## 📁 Repository Structure & Module Descriptions

1. **`data_pipeline.py`**:
   - Streams massive Wikipedia XML dumps lazily from `sys.stdin` or a local file using `xml.etree.ElementTree.iterparse`.
   - Extracts Document ID, Article Title, and Text body, appending to `docs.jsonl` as clean JSON.

2. **`indexer.py`**:
   - Tokenizes Hindi text preserving the Devanagari Unicode script while stripping punctuation and the Hindi Danda (`।`, `॥`).
   - Builds the inverted positional index in memory mapping each term to `{doc_id: [position_1, position_2, ...]}`.
   - Calculates Term Frequency ($TF$), Document Frequency ($DF$), and Collection Frequency ($CF$).
   - Writes the postings list to secondary storage (`postings.bin`) in a packed C-style binary format using Python's `struct` module:
     - Header: `<II` (DocID as 4-byte unsigned int, TF as 4-byte unsigned int)
     - Positions: `<{TF}I` (Array of 4-byte unsigned ints representing exact word positions)
   - Writes vocabulary mapping `term -> [byte_offset, DF, CF]` to `lexicon.json`.

3. **`query.py`**:
   - `BinarySearchEngine` core engine.
   - Keeps vocabulary in RAM (`self.lexicon`).
   - Memory-maps `postings.bin` to jump directly to secondary storage byte offsets and unpack postings on demand.
   - **Phrase Search**: Evaluates sequential phrase matches using $O(1)$ set intersection on position offsets.
   - **Proximity Search**: Checks whether two terms occur within distance $k$ of each other: $|pos_1 - pos_2| = k + 1$.
   - **Term Statistics Lookup**: Retrieves $DF$, $CF$, secondary storage byte offset, and full postings list.
   - Features both an interactive CLI and automated command-line flags (`--test`, `--rare`, `--term`, `--phrase`, `--proximity`, `--generate-output`).

4. **`app.py`**:
   - Flask-based web interface serving the search engine over HTTP.
   - Exposes REST API endpoint `/search` for phrase and proximity queries with millisecond execution timers.

5. **`templates/index.html`**:
   - Minimalist, responsive UI supporting instant AJAX search results.
   - Features a built-in virtual on-screen Hindi Devanagari keyboard (Vowels, Consonants, Matras, Halant).
   - Renders matching Document IDs, matched token positions, and expandable position lists.

6. **`output.txt`**:
   - It contains the test results on some cases
     - 5 test cases used to test the system (with matched doc IDs, token positions, and execution times).
     - 10 rare terms with their Document Frequency ($DF$), Collection Frequency ($CF$), and exact positional index.

## ⚙️ How to Run

### Prerequisites
- Python 3.8+
- Flask (`pip install flask`)

> **Note on Dataset Reproducibility:**  
> The file `docs.jsonl` included in this repository contains the fixed 10,000 Hindi Wikipedia articles used for this assignment. Building the index from `docs.jsonl` ensures 100% exact match with the results in `output.txt`.

### Step 1: Build the Index from `docs.jsonl`
To build `postings.bin` (secondary storage) and `lexicon.json` (vocabulary) from this dataset:
```bash
python3 indexer.py docs.jsonl postings.bin lexicon.json
```

---

### (Reference Only) Creating `docs.jsonl` from an XML Dump
If reproducing the extraction from a downloaded Wikipedia XML dump file:

- **From an uncompressed XML file:**
  ```bash
  python3 data_pipeline.py 10000 docs.jsonl < hiwiki-latest-pages-articles.xml
  ```

- **From a compressed `.xml.bz2` dump file:**
  ```bash
  bzip2 -dc hiwiki-latest-pages-articles.xml.bz2 | python3 data_pipeline.py 10000 docs.jsonl
  ```

*(Note: Live dumps from `dumps.wikimedia.org/hiwiki/latest/` are periodically regenerated by Wikipedia as articles get edited. Using the provided `docs.jsonl` guarantees identical results).*

## 🔍 How to Test the System

### Option A: Interactive Command-Line Menu
Run `query.py` without arguments to launch the interactive terminal interface:
```bash
python3 query.py
```
Menu options:
1. Phrase search (e.g. `भारत सरकार`)
2. Proximity search (e.g. `भारत` and `सरकार` with distance `1`)
3. Term Lookup (Show DF, CF, and Positional Postings List)
4. Run 5 Test Cases (from `test.txt`)
5. Show 10 Rare Terms Examples
6. Generate / Update `output.txt`
7. Exit

---

### Option B: Direct Command-Line Flags
You can run automated tests and queries directly from terminal commands:

- **Run the 5 Test Cases:**
  ```bash
  python3 query.py --test
  ```

- **Show 10 Rare Terms with Positional Index:**
  ```bash
  python3 query.py --rare
  ```

- **Lookup Single Term (CF, DF, and Postings):**
  ```bash
  python3 query.py --term "पदविज्ञान"
  ```

- **Run a Custom Phrase Search:**
  ```bash
  python3 query.py --phrase "भारत सरकार"
  ```

- **Run a Custom Proximity Search:**
  ```bash
  python3 query.py --proximity "भारत" "सरकार" 1
  ```

- **Regenerate Submission `output.txt`:**
  ```bash
  python3 query.py --generate-output
  ```

---

### Option C: Web Interface (GUI)
Start the Flask development server:
```bash
python3 app.py
```
Open your browser and navigate to:
```
http://localhost:5000
```
- Click **⌨️ Toggle Hindi Keyboard** to type in Devanagari script directly.
- Select **Phrase Search** or **Proximity Search**.
- Hit Enter or click **Search** to view results, matched positions, and millisecond latency.
